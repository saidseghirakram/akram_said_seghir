# Akram4Dev — Portfolio

Personal portfolio and case-study site for Akram Said Seghir (Software Engineer).

## Development

You need Node.js and npm — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```
